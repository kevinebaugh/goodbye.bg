Questions

Is goodbye.bg free?

Yes. Every photo, at full size, with no account, no credits, and no watermark.

Are my photos uploaded?

No. The background removal runs in your browser. Photos from your device never leave it. If you paste a link to a public image, our server fetches that image for you and keeps nothing.

What do I get back?

A PNG at the original size with a transparent background, or a white background if you turn that on. Download one photo or all of them as a zip.

Does it work on my phone?

Yes, in any modern browser. It is slower on phones than on computers because the work happens on your device.

Is there an API like remove.bg's?

No. goodbye.bg is a web page for people. The source code is open, so you can run it yourself.
