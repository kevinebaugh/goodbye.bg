Pindah dari remove.bg

Kredit Anda

Gunakan kredit remove.bg Anda sebelum 1 Desember 2026. Untuk langganan dan pengembalian dana, lihat halaman bantuan remove.bg dan halaman tagihan di akun Anda.

Kunci API Anda

Menurut remove.bg, layanan penghapus latar belakangnya pindah ke Leonardo.Ai pada 1 Desember 2026, jadi mulailah dari sana jika Anda memakai API-nya. goodbye.bg tidak punya API. Jika Anda butuh penghapus latar belakang di kode Anda sendiri, kode sumber goodbye.bg menunjukkan cara menjalankan model terbuka di browser, dan alat open source seperti rembg bisa berjalan di server Anda sendiri.

Pertanyaan

Apakah goodbye.bg gratis?

Ya. Setiap foto, dalam resolusi tinggi, tanpa akun, tanpa kredit, dan tanpa watermark.

Apakah foto saya diunggah?

Tidak. Penghapusan latar belakang berjalan di browser Anda, dan foto dari perangkat Anda tetap di sana. Mengeklik salah satu iklan produk membawa gambar itu ke Zazzle, supaya sudah ada di produk saat Anda tiba: server kami menyimpannya sampai Zazzle selesai menyalinnya (jika Zazzle tidak pernah menyalinnya, tidak ada yang bisa membukanya setelah satu jam dan file itu dihapus dalam satu hari). Jika Anda menempelkan tautan ke gambar publik, server kami mengambil gambar itu untuk Anda dan tidak menyimpan apa pun.

Apa yang saya dapat?

PNG dengan resolusi asli foto (hingga 16 megapiksel di Safari dan iPhone, 64 di tempat lain) dengan latar belakang transparan, dipangkas ke objek. GIF animasi kembali sebagai GIF animasi. Unduh satu foto atau semuanya sebagai ZIP.

Apakah bisa dipakai di HP?

Bisa, di browser modern mana pun. HP butuh beberapa detik per foto. Di iPhone, tekan lama hasilnya untuk menyimpannya ke Foto.

Apakah ada API seperti remove.bg?

Tidak. goodbye.bg adalah halaman web untuk manusia. Kode sumbernya terbuka, jadi Anda bisa menjalankannya sendiri.

Langkah demi langkah: cara menghapus latar belakang gambar.

Diperbarui 22 November 2026. goodbye.bg tidak berafiliasi dengan remove.bg atau Kaleido AI. remove.bg adalah merek dagang mereka.
